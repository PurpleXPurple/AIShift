How this was built & Credits:
This model is officially open-sourced on Hugging Face: ViolentlyPurple/Detect-AI.

It was fine-tuned completely on a local GTX 1050 Ti (ironic, but true). The pipeline involved parsing a 332k row CSV, balancing classes via WeightedRandomSampler, truncating sequences to 64 tokens, freezing the bottom 4 DistilBERT layers, and applying a custom weighted CrossEntropy loss to penalize false positives. You can replicate this by using the finetune.py script provided in the repository.
