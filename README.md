# AISniff: Custom AI Text Detection (ViolentlyPurple/Detect-AI)

## Overview
**AISniff** is an open-source, locally hosted AI text detection platform. It is powered by a custom fine-tuned DistilBERT model (`ViolentlyPurple/Detect-AI`). 

Unlike commercial detectors that hide behind proprietary APIs, AISniff runs entirely on your local hardware. It provides probabilistic outputs, complete transparency regarding its limitations, and an open dataset contribution pipeline. This project was born out of a need to fix the severe false-positive rates of standard open-source detectors on casual, informal, and non-native human writing.

## The Base Model
This project is a fine-tuned derivative of the open-source **[akshayvkt/detect-ai-text](https://huggingface.co/akshayvkt/detect-ai-text)** model. 
*   **Architecture:** DistilBERT (a lighter, faster version of BERT)
*   **Parameters:** 67 Million
*   **Original Training:** DistilBERT pre-trained on English Wikipedia and Toronto Book Corpus, then fine-tuned specifically for text classification.

## Training Hardware & Specifications
The model was trained entirely on consumer-grade hardware, proving that you don't need enterprise GPUs to build functional AI detectors.
*   **GPU:** NVIDIA GeForce GTX 1050 Ti (4GB VRAM)
*   **OS:** Windows 11
*   **Environment:** Python 3.12, PyTorch with CUDA 12.1
*   **Libraries:** `transformers`, `datasets`, `scikit-learn`, `pandas`, `numpy`

## The Dataset Pipeline
The training pipeline involved aggressive data balancing and sequence truncation to fit within the 1050 Ti's VRAM limits while maximizing generalization.

### 1. Data Collection
The dataset was scraped using custom tools (`scrape.py`) leveraging `curl-cffi` (Chrome TLS impersonation) and `selectolax.lexbor`. It gathered:
*   **Human Text:** High-quality RSS feeds (Guardian, BBC, Wired, TechCrunch), Reddit writing forums, and manually verified human interactions.
*   **AI Text:** Reddit communities dedicated to AI roleplay (`r/WritingWithAI`, `r/NovelAI`, `r/AIDungeon`) and raw outputs from LLMs.
*   **Interactive Data:** A custom built FastAPI labeling server (`dataset.py`) was used to manually label edge-case text, adding 105 highly curated human/AI pairs.

### 2. Preprocessing & Optimization
To train efficiently on the 332,000+ row dataset:
*   **Sequence Length:** Truncated to **64 tokens**. AI detection heavily relies on vocabulary choice in the first few sentences; longer sequences waste compute.
*   **Class Balancing:** Used PyTorch’s `WeightedRandomSampler` to ensure the model saw an exact 50/50 split of Human and AI text in every batch, preventing majority-class bias.
*   **Custom Loss Function:** Implemented a weighted `CrossEntropyLoss` that penalizes false positives (guessing "AI" on human text) by **2x**. This drastically improved Precision.

## Benchmark Results
The baseline model was highly aggressive, flagging 80-90% of casual human text as AI. The fine-tuned model was tested against a 34-case adversarial stress test (including slang, tech jargon, run-on sentences, and AI roleplay).

| Metric | Original Baseline | Custom Fine-Tuned (Ours) |
| :--- | :--- | :--- |
| **Accuracy** | 67.65% | **94.12%** |
| **Precision** | 60.71% | **100.00%** |
| **Recall** | 100.00% | 88.24% |
| **F1 Score** | 75.56% | **93.75%** |
| **Avg Latency** | 13.04 ms | **8.67 ms** |

The **100% Precision** means the model made *zero* false accusations against human text during the stress test. It would rather miss an AI text (lower recall) than falsely accuse a human.

## The Full Stack Architecture
This repository includes the complete infrastructure to host the model locally:
*   `Server.py`: The FastAPI backend, featuring rate limiting, strict security headers, and local Proof-of-Work CAPTCHA generation.
*   `ml.py`: The optimized PyTorch inference engine.
*   `index.html`: A zero-dependency Vanilla JS frontend with dark mode, benchmark tables, and legal disclaimers.
*   `finetune.py`: The native PyTorch training loop.
*   `scrape.py`: The data collection pipeline.
